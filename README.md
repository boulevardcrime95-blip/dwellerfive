# Idéverkstan

En liten, fristående prototyp för att samla produktidéer, göra en förenklad kostnadskalkyl och planera vad du själv behöver kontrollera.

## Starta

Öppna `index.html` i en modern webbläsare. Appen använder inga paket eller externa tjänster. Idéerna sparas lokalt i webbläsaren på enheten.

## Kalkyl

Den uppskattade marginalen räknas som tänkt försäljningspris minus inköpspris, frakt per produkt och den procentuella avgiften beräknad på försäljningspriset. Resultatet är en grov uppskattning, inte en garanti för försäljning eller intäkter, och tar inte hänsyn till alla skatter, returer eller andra kostnader.

## AI-promptar

Gransknings- och produktsidetextknapparna skapar endast promptutkast som du kan kopiera själv. Ingen AI-tjänst anropas och inga leverantörs- eller marknadsuppgifter hämtas automatiskt.

Appen publicerar, annonserar, beställer eller tar inte emot betalningar. Du ansvarar själv för att kontrollera uppgifter och godkänna varje steg.
